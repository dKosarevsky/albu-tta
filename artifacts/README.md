# Artifacts

This directory is reserved for generated experiment outputs and local data.

Do not commit ImageNet images, teacher logits caches, selector checkpoints, generated reports,
or private evaluation outputs unless a specific file is intentionally promoted to documentation.

`augmentation_registry_audit.json` is generated by `validate-augmentations --audit-output`
and records the exact candidate ids, transform classes, parameters, seed, and serialized
AlbumentationsX `Compose` payloads used for a run.
